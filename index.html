Enter your free Supabase project details and a sync key (any phrase — use the same one on every device). One-time SQL setup is shown below.

One-time database setup (SQL) 
create table if not exists collections (
  id text primary key,
  data jsonb not null default '[]',
  updated_at timestamptz not null default now()
);
alter table collections enable row level security;
create policy "anon access" on collections
  for all to anon using (true) with check (true);

Run this once in your Supabase project's SQL editor. Note: anyone with your URL, anon key, and sync key could read this data — fine for a hobby list, but don't store anything sensitive.
